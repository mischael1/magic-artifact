🚀 СБОРКА БЕЗ ЛИШНИХ СЛОВ
═══════════════════════════════════════════════════════════════

1. Проверка: .\prepare_local_build.ps1
2. Выбрать один из трёх:
   
   A) DOCKER:
      docker-compose -f docker-compose.android.yml build --no-cache
      docker-compose -f docker-compose.android.yml up
   
   B) POWERSHELL:
      .\install_buildozer_deps.ps1
      .\build_apk_local.ps1
   
   C) БАТНИК:
      ЗАПУСТИ_СБОРКУ.bat (два клика)

3. Ждать 20-40 минут
4. Результат: bin\magicartifact-0.1-debug.apk
5. Установить: adb install -r bin\magicartifact-0.1-debug.apk

📱 УСТАНОВКА НА ПЛАНШЕТ
═══════════════════════════════════════════════════════════════

С ADB (если установлен):
  adb install -r bin\magicartifact-0.1-debug.apk

Без ADB (USB копирование):
  1. Копировать bin\magicartifact-0.1-debug.apk на USB
  2. Вставить USB в планшет
  3. Открыть файл в файловом менеджере
  4. Установить приложение
