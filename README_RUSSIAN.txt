📖 КАК НАЧАТЬ (выберите один из способов):

1️⃣  ОБЛАКО (самый простой) - GitHub Actions
   └─ Ничего не устанавливайте на компьютер
   └─ GitHub автоматически соберет APK
   └─ Документация: откройте QUICK_BUILD.md

2️⃣  ЛОКАЛЬНО (Windows) - WSL2 + buildozer
   └─ Установите WSL2 и buildozer
   └─ Собирайте на своем компьютере
   └─ Документация: откройте INSTALLATION.md

3️⃣  LINUX/MAC - Быстрая сборка
   └─ Запустите: python3 build_apk.py
   └─ Документация: откройте BUILD_APK.md

🎯 БЫСТРАЯ ИНСТРУКЦИЯ:

ШАГ 1: Выберите способ сборки
   ☐ Облако (GitHub Actions) - см. QUICK_BUILD.md
   ☐ WSL2 на Windows - см. INSTALLATION.md (Способ 2)
   ☐ Linux/Mac - запустите: python3 build_apk.py

ШАГ 2: Получите файл magicartifact-0.1-debug.apk
   
ШАГ 3: Установите на планшет
   Команда: adb install -r magicartifact-0.1-debug.apk
   Или вручную через файловый менеджер планшета

ШАГ 4: Запустите приложение
   На планшете откройте "Магический Артефакт"

ШАГ 5: Используйте на игре
   Говорите громко → Скажите заклинание → Видите эффект
