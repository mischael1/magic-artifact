═══════════════════════════════════════════════════════════════
  🚀 БЫСТРЫЙ СТАРТ (3 МИНУТЫ)
═══════════════════════════════════════════════════════════════

1. Откройте PowerShell в папке проекта

2. Выполните:
   .\prepare_local_build.ps1

3. Скопируйте команду из:
   СЕЙЧАС_ЗАПУСК.txt

4. Выполните команду и ждите 20-40 минут

5. APK будет в: bin\magicartifact-0.1-debug.apk

═══════════════════════════════════════════════════════════════

Для ПЕРВОЙ сборки:

1. НАЧНИТЕ_ОТСЮДА.txt         (5 мин) ← НАЧНИ ОТСЮДА!
2. .\prepare_local_build.ps1   (2 мин) ← ПРОВЕРЬ
3. СЕЙЧАС_ЗАПУСК.txt          (1 мин) ← СКОПИРУЙ КОМАНДУ
4. Выполни сборку             (20-40 мин)
5. ЛОКАЛЬНАЯ_СБОРКА.md        (если ошибка)

Для СЛЕДУЮЩИХ сборок:

1. .\build_apk_local.ps1       (5-15 мин) ← БЫСТРО!
