# ИНСТРУКЦИЯ ПО РАЗВЕРТЫВАНИЮ МАГИЧЕСКОГО АРТЕФАКТА

## 📋 Обзор

Полностью готовое к использованию приложение "Магический Артефакт" для полевых ролевых игр с голосовым управлением.

## 🎯 Что уже реализовано

### ✅ Базовый функционал
- **Полноэкранный киоск-режим** - приложение занимает весь экран
- **Отключение спящего режима** - экран не гаснет
- **Магический интерфейс** - анимированный фон с частицами
- **Медиаплеер** - воспроизведение изображений заклинаний

### ✅ Голосовое управление
- **Wake-word detection** - постоянно слушает фразу "артефакт"
- **Speech recognition** - распознает заклинания на русском языке
- **Офлайн работа** - не требует интернета

### ✅ Система заклинаний
- **База заклинаний** - JSON файл с настраиваемыми заклинаниями
- **Множественные триггеры** - несколько фраз для каждого заклинания
- **Медиаэффекты** - изображения для визуальных эффектов
- **Автосброс** - возврат к прослушиванию через 30 секунд

## 🚀 Быстрый старт

## 🎮 Использование на планшете

### Режим работы
1. **Киоск-режим** - приложение занимает весь экран
2. **Постоянное прослушивание** - ждет wake-word "артефакт"
3. **Активация заклинаний** - после wake-word распознает речь
4. **Автосброс** - через 30 секунд возвращается к прослушиванию

### Доступные заклинания
- **Огненный шар** - активируется фразами: "огненный шар", "фаер болл"
- **Лечение** - активируется фразами: "лечение", "хил", "исцеление"
- **Магический щит** - активируется фразами: "щит", "защита", "магический щит"

### Визуальные эффекты
- Магические частицы на фоне
- Изображения заклинаний
- Анимированные переходы
- Цветовые индикаторы состояния

## 🔧 Кастомизация

### Добавление новых заклинаний

1. Откройте `data/spells.json`
2. Добавьте новое заклинание:

```json
{
  "название_заклинания": {
    "name": "Отображаемое название",
    "trigger_words": ["фраза1", "фраза2", "фраза3"],
    "description": "Описание заклинания",
    "media": {
      "image": "spells/new_spell/image.jpg",
      "sound": "spells/new_spell/sound.mp3"
    },
    "duration": 5000,
    "effects": ["effect1", "effect2"]
  }
}
```

3. Создайте медиафайлы в папке `assets/spells/new_spell/`

### Изменение wake-word

Измените в `data/spells.json`:
```json
{
  "meta": {
    "wake_word": "ваша_фраза"
  }
}
```

## 🐛 Устранение проблем

### Частые проблемы

**Проблема: Kivy не запускается**
```bash
# Переустановка Kivy
pip uninstall kivy
pip install kivy
```

**Проблема: Голос не работает**
```bash
# Проверка библиотек
python -c "import openwakeword, vosk; print('OK')"
```

**Проблема: APK не собирается**
```bash
# Очистка и пересборка
buildozer android clean
buildozer android debug
```

**Проблема: Нет звука на планшете**
- Проверьте разрешения в настройках Android
- Убедитесь что громкость не на нуле
- Проверьте что аудиофайлы существуют

### Отладка
```bash
# Запуск с логами
python full_magic_app.py 2>&1 | tee debug.log

# Проверка компонентов
python -c "
from src.spell_manager import SpellManager
sm = SpellManager()
print('Заклинаний:', len(sm.get_all_spells_info()))
"
```
