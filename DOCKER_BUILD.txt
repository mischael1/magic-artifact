✅ ШАГ 1: УСТАНОВИТЕ DOCKER DESKTOP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Windows:  https://www.docker.com/products/docker-desktop
macOS:    https://www.docker.com/products/docker-desktop
Linux:    sudo apt-get install docker.io

После установки перезагрузитесь.


✅ ШАГ 2: ЗАПУСТИТЕ СБОРКУ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

WINDOWS (в PowerShell):
  cd C:\Users\GIGABYTE\opencode
  .\docker-build.bat

LINUX/MAC (в терминале):
  cd ~/opencode
  bash docker-build.sh

Скрипт сделает всё:
  1. Создаст Docker образ (~5-10 минут, первый раз)
  2. Соберет APK (~10-20 минут)
  3. Сохранит в bin/magicartifact-0.1-debug.apk


✅ ШАГ 3: УСТАНОВИТЕ НА ПЛАНШЕТ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

adb install -r bin/magicartifact-0.1-debug.apk


⏱️ ОЖИДАЕМОЕ ВРЕМЯ:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Первый раз:   15-20 минут (создание образа)
В следующий раз:  10-15 минут (только сборка)


🆘 ЕСЛИ НЕ РАБОТАЕТ:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Проверьте что Docker запущен:
  docker version

Если ошибка "daemon not running":
  1. Откройте Docker Desktop
  2. Дождитесь пока оно загрузится
  3. Повторите команду

ФАЙЛЫ В ПРОЕКТЕ:

  Dockerfile          - Конфигурация для Docker
  docker-build.bat    - Скрипт для Windows
  docker-build.sh     - Скрипт для Linux/Mac

ИТОГО: 3 команды и вы получите готовый APK!

1. Установить Docker Desktop
2. Запустить docker-build.bat (или .sh)
3. Установить APK на планшет
