# Тестовые медиафайлы

В этой папке должны находиться тестовые медиафайлы для демонстрации работы приложения.

## Структура папок:
```
assets/
├── sounds/                 # Звуковые эффекты
│   ├── wake_detected.mp3   # Звук обнаружения wake-word
│   ├── spell_success.mp3    # Звук успешного заклинания
│   └── spell_fail.mp3      # Звук ошибки
├── spells/                 # Медиа заклинаний
│   ├── fireball/          # Огненный шар
│   │   ├── video.mp4      # Видео эффекта
│   │   ├── image.jpg      # Изображение эффекта
│   │   └── sound.mp3      # Звук эффекта
│   ├── heal/              # Лечение
│   │   ├── video.mp4
│   │   ├── image.jpg
│   │   └── sound.mp3
│   └── shield/            # Защитный щит
│       ├── video.mp4
│       ├── image.jpg
│       └── sound.mp3
└── images/                 # Общие изображения
    ├── background.jpg       # Фон артефакта
    └── default_spell.jpg   # Изображение по умолчанию
```

## Рекомендуемые форматы:
- **Видео**: MP4 (H.264), 1280x720, 24-30 FPS, 2-5 Mbps
- **Аудио**: MP3, 44.1 kHz, 128-320 kbps, 2-8 секунд
- **Изображения**: JPG/PNG, 1280x720, качество 80-95%

## Временное решение:
Для тестирования можно использовать любые медиафайлы:
- Скачать бесплатные видеоэффекты с Pixabay
- Использовать аудиофайлы из библиотек звуков
- Создать простые изображения в графическом редакторе

## Инструкция по созданию:
1. Найдите или создайте медиафайлы
2. Переименуйте их согласно структуре выше
3. Разместите в соответствующих папках
4. Проверьте пути в spells.json

## Для быстрого теста:
Можно временно закомментировать медиафайлы в spells.json,
оставив только текстовые уведомления.
