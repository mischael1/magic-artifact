КАК ПОЛУЧИТЬ APK:

ВАРИАНТ 1: ОБЛАКО (GitHub Actions) - РЕКОМЕНДУЕТСЯ ⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Время: 25 минут
Сложность: Очень простая
Требует: GitHub аккаунт
Процесс: 
  1. Загрузите проект на GitHub
  2. Создайте .github/workflows/build.yml (см. QUICK_BUILD.md)
  3. GitHub собирает APK автоматически
  4. Скачайте из Artifacts

ВАРИАНТ 2: ЛОКАЛЬНО НА WINDOWS (WSL2)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Время: 3 часа (первый раз), 15 мин (потом)
Сложность: Средняя
Требует: WSL2, Android SDK/NDK, buildozer
Процесс:
  1. Установите WSL2
  2. Установите Android SDK и NDK в WSL
  3. Запустите: buildozer android debug
  4. Найдите APK в bin/

ВАРИАНТ 3: LINUX/MAC (быстро)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Время: 15-20 минут
Сложность: Средняя
Требует: Android SDK/NDK, buildozer
Процесс:
  1. Установите зависимости
  2. Запустите: python3 build_apk.py
  3. Дождитесь завершения

КАК УСТАНОВИТЬ НА ПЛАНШЕТ:

1. Подключите планшет по USB кабелю

2. Включите режим разработчика:
   Settings → About → Нажмите 7 раз на "Build number"
   Settings → Developer options → Enable USB debugging

3. Установите приложение:
   adb install -r bin/magicartifact-0.1-debug.apk

   Или вручную:
   - Скопируйте APK на планшет
   - Откройте файловый менеджер
   - Нажмите на APK и установите

4. Запустите приложение:
   Откройте "Магический Артефакт" на планшете
