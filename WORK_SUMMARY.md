## 🔍 Технические детали

### Сценарий работы
```
1. Приложение запускается
   ↓
2. Инициализирует микрофон и Vosk
   ↓
3. Слушает ключевое слово "артефакт"
   ↓
4. Когда услышано "артефакт" → переходит в режим ожидания заклинания
   ↓
5. Слушает произнесение заклинания (щит, огонь, лед и т.д.)
   ↓
6. Анализирует текст и ищет в базе
   ↓
7. Если найдено → воспроизводит звук + анимация
   ↓
8. Через 3 сек возвращается в режим ожидания ключевого слова
```

## 📝 Ключевые особенности реализации

### 1. Многоплатформность
- **expect/actual** pattern для Desktop и Android различий
- **commonMain** для общей логики (SpellManager, UI)
- **desktopMain** только Java-specific код
- **androidMain** только Android-specific код

### 2. Распознавание речи
**Desktop**: Эвристика на основе длительности и энергии звука (быстро прототипировать)
**Android**: Vosk готов к интеграции (реальное распознавание русского)

### 3. Звуковые эффекты
Процедурно генерируемые синусоидальные тоны с:
- Разной базовой частотой для каждого заклинания
- Частотной модуляцией для эффекта
- Огибающими (fade in/out) для естественности
- Работает без файлов, только код

### 4. UI Компоненты
```kotlin
MagicArtifactApp              // Главный экран
├── MagicArtifactWidget       // Анимированный артефакт
├── Text (статус)             // Информационные сообщения
├── Text (заклинание)         // Название активного заклинания
└── Button (слушание)         // Управление микрофоном
```

### 5. Hot Reload
- Gradle watch mode (`-t` флаг)
- Автоматическая перекомпиляция при изменении UI
- Сохранение состояния приложения между обновлениями
