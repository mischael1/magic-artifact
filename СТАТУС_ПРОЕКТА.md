## 📈 Жизненный цикл сборки

```
1. ПОДГОТОВКА (1-2 мин)
   └─ Проверка зависимостей
   └─ Подготовка файлов

2. СКАЧИВАНИЕ (первый раз: 5-10 мин)
   └─ Android SDK (~2 GB)
   └─ Platform Tools
   └─ Build Tools
   └─ NDK
   (Используется кеш потом)

3. КОМПИЛЯЦИЯ (5-10 мин)
   └─ Компиляция Python кода
   └─ Компиляция зависимостей (numpy, kivy)
   └─ Подготовка ресурсов

4. УПАКОВКА (3-5 мин)
   └─ Создание APK
   └─ Подпись
   └─ Финализация

5. ЗАВЕРШЕНИЕ (1 мин)
   └─ Проверка результата
   └─ APK в bin/magicartifact-0.1-debug.apk
```

**Итого первый раз:** 20-40 минут (с Android SDK)  
**Итого потом:** 5-15 минут (кеш готов)

## 💾 Кеширование

### Где хранится кеш

**Docker:** в контейнере (контейнер хранит состояние)  
**PowerShell:** `%USERPROFILE%\.buildozer`

### Когда использовать кеш

- Пересборка: используется автоматически (~5-10 минут)
- После изменения кода: кеш ускорит сборку

### Очистка кеша

```powershell
# Полная пересборка с очисткой
.\build_apk_local.ps1 -Clean

# Или вручную
Remove-Item -Path $env:USERPROFILE\.buildozer -Recurse -Force
```
