🚀 ВСЕ ПРОСТО:

1️⃣  ПОДГОТОВКА (5 мин)
   ───────────────────────────────────────────────────────────
   
   а) На компьютере сожми папку opencode в ZIP:
      Правый клик → Отправить → Сжатая папка
      
      Получится: opencode.zip
   
   б) Открой Google Colab в браузере:
      https://colab.research.google.com


2️⃣  ЗАГРУЗКА NOTEBOOK (1 мин)
   ───────────────────────────────────────────────────────────
   
   В Colab:
   File → Upload notebook → COLAB_BUILD.ipynb
   
   (или просто откройте по ссылке:)
   https://colab.research.google.com/github/mischael1/magic-artifact/blob/main/COLAB_BUILD.ipynb


3️⃣  ЗАГРУЗКА ZIP (1 мин)
   ───────────────────────────────────────────────────────────
   
   Нажмите Files (📁) слева
   Upload → Выберите opencode.zip
   Дождитесь загрузки


4️⃣  ЗАПУСТИ ЯЧЕЙКИ ПО ПОРЯДКУ (40 мин)
   ───────────────────────────────────────────────────────────
   
   Ячейка 1: ▶ Run → Распаковка ZIP (1 мин)
   Ячейка 2: ▶ Run → Зависимости (5 мин)
   Ячейка 3: ▶ Run → Android SDK (10-15 мин)
   Ячейка 4: ▶ Run → Сборка APK (10-20 мин)
   Ячейка 5: ▶ Run → Информация скачивания


5️⃣  СКАЧАЙ APK (1 мин)
   ───────────────────────────────────────────────────────────
   
   Files (📁) → bin → magicartifact-0.1-debug.apk
   Правый клик → Download


6️⃣  УСТАНОВИ НА ПЛАНШЕТ
   ───────────────────────────────────────────────────────────
   
   adb install -r magicartifact-0.1-debug.apk
   
   Или скопируй файл APK на планшет и откройте его там
