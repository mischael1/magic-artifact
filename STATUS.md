### 🚀 Способы сборки APK

#### Вариант 1: Docker (рекомендуется)
```bash
# Требует: Docker Desktop
python build_apk_docker.py
```

#### Вариант 2: WSL2
```bash
# Требует: WSL2 + Ubuntu + Java + Buildozer
wsl
cd /mnt/c/Users/GIGABYTE/opencode
buildozer android debug
```

#### Вариант 3: Google Colab
```
Откройте COLAB_BUILD.ipynb в Google Colab
```

#### Вариант 4: GitHub Actions
```
Push на GitHub → автоматическая сборка
```

### ⏱️ Время сборки

| Этап | Время | Примечание |
|------|-------|-----------|
| Docker образ | 10-15 мин | Только первый раз |
| Скачивание SDK | 15-25 мин | Зависит от интернета |
| Сборка APK | 10-20 мин | Параллельная обработка |
| **ИТОГО первый раз** | **45-60 мин** | |
