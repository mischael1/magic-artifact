## 🚀 Что запустить сейчас

### Для разработки Desktop:
```bash
./run_with_hot_reload.ps1
```

### Для Android сборки:
```bash
# Скачать модель Vosk (один раз)
./download_vosk_model.ps1

# Собрать APK
./gradlew assembleDebug

# Или установить на подключенное устройство
./gradlew installDebug
```

## ⚡ Быстрые команды

| Команда | Описание |

## 🎓 Примеры использования

### Добавить новое заклинание:
Отредактировать `SpellManager.kt`:
```kotlin
Spell(
    id = "mystic_shield",
    name = "Мистический Щит",
    keywords = listOf("мистический", "магический", "щит"),
    description = "Мистический щит защиты"
)
```

### Изменить цвет UI:
В `MagicArtifactApp.kt`:
```kotlin
Color(0xffe6b3ff)  // Фиолетовый → измените на другой hex
```

### Изменить звук заклинания:
В `SoundEffects.kt`:
```kotlin
"myspell" -> Triple(1500, 400, 0.4)  // Частота, длительность, модуляция
```

## ⚠️ Важные замечания

1. **Для Desktop**: Нужна Java 11+
2. **Для Android**: Нужна Android SDK 21+ и модель Vosk
3. **Hot Reload**: Работает только для UI изменений, не для логики
4. **Vosk модель**: ~50MB, скачивается один раз
5. **Микрофон**: Должен быть включен и доступен приложению

## 📞 Поддержка

Если что-то не работает:

### Desktop не запускается:
```bash
./gradlew clean
./gradlew composeApp:runDesktop
```

### Android не собирается:
```bash
./gradlew clean
./gradlew assembleDebug
```

### Нет звука:
- Проверьте громкость
- Убедитесь, что не в режиме без звука
- Перезагрузите приложение

### Микрофон не работает:
- Проверьте разрешения в параметрах
- Убедитесь, что нет других приложений с микрофоном
- На Android: Settings > Apps > Magic Artifact > Permissions > Audio
