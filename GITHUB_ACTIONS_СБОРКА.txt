СПОСОБ 1: Автоматическая сборка на PUSH (рекомендуется)
──────────────────────────────────────────────────────────
Просто делайте commit и push в main/master:

  git add .
  git commit -m "Ваши изменения"
  git push

Сборка начнется автоматически!


СПОСОБ 2: Ручная сборка через GitHub UI
──────────────────────────────────────────────────────────
1. Откройте репозиторий на GitHub:
   https://github.com/mischael1/magic-artifact

2. Перейдите: Actions → Build APK

3. Нажмите: Run workflow

4. Выберите ветку (main) и запустите


СПОСОБ 3: Ручная сборка через gh CLI
──────────────────────────────────────────────────────────
Если установлен GitHub CLI:

  gh workflow run build-apk.yml

ВАРИАНТ 1: Через GitHub Releases
──────────────────────────────────────────────────────────
1. Откройте: https://github.com/mischael1/magic-artifact/releases

2. Найдите последний Release с версией APK

3. Скачайте файл: magicartifact-0.1-debug.apk


ВАРИАНТ 2: Через GitHub Actions Artifacts
──────────────────────────────────────────────────────────
1. Откройте: https://github.com/mischael1/magic-artifact/actions

2. Найдите последний успешный workflow "Build APK"

3. Прокрутите вниз до "Artifacts"

4. Скачайте: magicartifact-apk


ВАРИАНТ 3: Напрямую через GitHub UI
──────────────────────────────────────────────────────────
1. Actions → Build APK → последний workflow
2. Artifacts → magicartifact-apk → Download

═══════════════════════════════════════════════════════════════
  📊 МОНИТОРИНГ СБОРКИ
═══════════════════════════════════════════════════════════════

1. Откройте GitHub Actions:
   https://github.com/mischael1/magic-artifact/actions

2. Смотрите статус сборки:
   ✅ Success - сборка успешна, APK готова
   ❌ Failed - ошибка, смотрите логи
   🔄 In progress - сборка идет

3. Нажмите на workflow для просмотра логов


═══════════════════════════════════════════════════════════════
  🐛 ЕСЛИ СБОРКА УПАЛА
═══════════════════════════════════════════════════════════════

1. Откройте workflow в Actions

2. Нажмите "Run workflow"

3. Посмотрите логи в разделе "Build"

4. Исправьте ошибку в коде локально

5. Запушьте исправления

6. Сборка запустится заново
