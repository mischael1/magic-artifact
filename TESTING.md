# Тестирование приложения Магический Артефакт

## Локальное тестирование на PC (без сборки APK)

### Вариант 1: Быстрый тест (консольное приложение)

```bash
# Установите зависимости
pip install kivy numpy

# Запустите главное приложение
python main.py
```

### Вариант 2: Тест модулей отдельно

#### Тест SpellManager
```bash
cd src
python spell_manager.py
```

Ожидаемый результат:
```
Загружено 5 заклинаний
Тестирование поиска заклинаний:
'огненный шар' -> Огненный шар
'фаер болл' -> Огненный шар
...
```

#### Тест VoiceManager
```bash
python voice_manager.py
```

Это будет имитировать распознавание речи в течение 10 секунд.

## Тестирование на эмуляторе Android

### Требования

- Android Studio
- Android Emulator
- 4+ GB RAM на компьютере

### Установка эмулятора

1. Откройте Android Studio
2. **Tools** → **AVD Manager** → **Create Virtual Device**
3. Выберите **Pixel 4** (или похожий)
4. Выберите Android 11 (API 30) или выше
5. Завершите создание
6. Запустите эмулятор

### Сборка и установка

```bash
# Собрать APK
python3 build_apk.py

# Или через buildozer (если установлен)
buildozer android debug

# Найти APK
ls bin/*.apk

# Установить на эмулятор
adb install -r bin/magicartifact-0.1-debug.apk

# Запустить
adb shell am start -n org.magicartifact/.MainActivity
```

### Проверка логов

```bash
# Реальные логи приложения
adb logcat | grep magicartifact

# Или все логи
adb logcat
```

## Тестирование на реальном планшете

### Требования

- Планшет с Android 5.0+
- USB кабель
- Режим разработчика включен
- Разрешение на отладку по USB

### Включение режима разработчика

1. Откройте **Настройки** → **О планшете**
2. Нажмите 7 раз на **Номер сборки**
3. Вернитесь в Настройки
4. Откройте **Параметры разработчика** (новый пункт)
5. Включите **Отладку по USB**

### Установка

```bash
# Проверить подключение
adb devices

# Должно вывести что-то вроде:
# List of attached devices
# ABC123DEF456 device

# Установить приложение
adb install -r bin/magicartifact-0.1-debug.apk

# Разрешить установку из неизвестных источников если потребуется
```

### Отладка на планшете

```bash
# Смотреть логи
adb logcat

# Фильтровать по пакету
adb logcat | grep org.magicartifact

# Сохранить логи в файл
adb logcat > logcat.txt

# Запустить приложение
adb shell am start -n org.magicartifact/.MainActivity

# Остановить приложение
adb shell am force-stop org.magicartifact

# Удалить приложение
adb uninstall org.magicartifact
```

## Сценарии тестирования

### Сценарий 1: Базовое функциональность

1. Запустите приложение
2. Убедитесь, что на экране отображается "МАГИЧЕСКИЙ АРТЕФАКТ"
3. Проверьте статус: "Слушаю пробуждение..."
4. Внесите шум / произнесите что-то громко
5. Статус должен измениться на "Пробуждение обнаружено!"
6. Произнесите название заклинания (например, "щит")
7. Проверьте, что появилось сообщение о активации заклинания

### Сценарий 2: Распознавание заклинаний

Протестируйте каждое заклинание:
- "щит" / "защита" / "shield" → Магический щит
- "огненный шар" / "фаер болл" / "fireball" → Огненный шар
- "лечение" / "хил" / "heal" → Лечебное заклинание
- "молния" / "электричество" / "lightning" → Молния
- "темная стрела" / "дарк болт" / "dark bolt" → Темная стрела

### Сценарий 3: Автосброс

1. Активируйте приложение
2. Дождитесь 30 секунд
3. Проверьте, что статус вернулся на "Слушаю пробуждение..."

### Сценарий 4: Полноэкранный режим

1. Нажмите Home на планшете
2. Приложение должно остаться на экране (киоск-режим не позволяет выход)
3. Нажмите Back - приложение не должно закрыться

adb shell dumpsys batterstats | grep -A 20 "Approximate Battery"

## Отладка проблем

### Приложение зависает при запуске

```bash
# Очистите кэш и данные
adb shell pm clear org.magicartifact

# Переустановите
adb uninstall org.magicartifact
adb install bin/magicartifact-0.1-debug.apk

# Смотрите логи во время загрузки
adb logcat | grep org.magicartifact
```

### Нет звука на эмуляторе

Это нормально - эмулятор часто не поддерживает аудио полностью.
Тестируйте на реальном устройстве.

### Приложение не запускается

```bash
# Проверьте permission'ы
adb shell pm list permissions -g | grep RECORD_AUDIO

# Проверьте установку
adb shell pm dump org.magicartifact | head -20

# Посмотрите детальные логи
adb logcat -s *:E *:W | grep -i magic
```

### Микрофон не работает

На планшете:
1. Откройте **Настройки** → **Приложения** → **Магический Артефакт**
2. Откройте **Разрешения**
3. Убедитесь, что **Микрофон** разрешен
4. Попробуйте другое приложение с микрофоном (диктофон) для проверки

## Автоматизированное тестирование

Создайте файл `test_app.py` для автотестов:

```python
import unittest
from src.spell_manager import SpellManager

class TestSpellManager(unittest.TestCase):
    def setUp(self):
        self.manager = SpellManager()
    
    def test_load_spells(self):
        self.assertGreater(len(self.manager.spells_data.get('spells', {})), 0)
    
    def test_find_spell(self):
        spell = self.manager.find_spell("щит")
        self.assertIsNotNone(spell)
        self.assertEqual(spell, "магический_щит")
    
    def test_unknown_spell(self):
        spell = self.manager.find_spell("несуществующее заклинание")
        self.assertIsNone(spell)

if __name__ == '__main__':
    unittest.main()
```

Запуск:
```bash
python -m unittest test_app.py -v
```
