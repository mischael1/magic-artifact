СПОСОБ 1 (Самый простой):
═════════════════════════
1. Откройте командную строку (cmd.exe)
2. Перейдите в папку проекта:
   cd c:\Users\GIGABYTE\opencode

3. Запустите:
   gradlew composeApp:run

4. Дождитесь загрузки (30-60 сек первый раз)


СПОСОБ 2 (Через PowerShell):
════════════════════════════
1. Откройте PowerShell
2. Выполните:
   cd 'c:\Users\GIGABYTE\opencode'
   .\gradlew.bat composeApp:run


СПОСОБ 3 (Через батник):
═════════════════════════
1. Найдите файл "start.bat" в папке проекта
2. Двойной клик по нему


ЧТО ТЕСТИРОВАТЬ:
═══════════════
1. Когда окно откроется, нажмите зелёную кнопку "🎤 СЛУШАТЬ"
2. Произнесите чётко одно из слов:
   - "ОГОНЬ" (низкий голос, открытый звук)
   - "ЛЕД" (более высокие частоты)
   - "МОЛНИЯ" (среднее)

3. Проверьте:
   ✓ Какое слово вы произнесли
   ✓ Что написано в статусе
   ✓ Появилась ли красная вспышка в центре


НОВЫЕ УЛУЧШЕНИЯ:
════════════════
✓ MFCC анализ (mel-frequency cepstral coefficients)
✓ Анализ форманта (специфические резонансные частоты гласных)
✓ Спектральный центр тяжести (различие высоких/низких частот)
✓ Озвученность (различие гласных от согласных)

Это должно лучше различать произносимые слова, чем старый алгоритм.


ЕСЛИ НЕ РАБОТАЕТ:
═════════════════
1. Проверьте, что Java установлена:
   java -version

2. Если Java не найдена, скачайте JDK 11+:
   https://www.oracle.com/java/technologies/javase-jdk11-downloads.html

3. Если ошибка компиляции - скопируйте её и отправьте на проверку
