ВЫБЕРИТЕ СПОСОБ И СКОПИРУЙТЕ КОМАНДУ:


▼▼▼ СПОСОБ 1: DOCKER (РЕКОМЕНДУЕТСЯ) ▼▼▼

Откройте PowerShell/cmd и выполните:

    cd C:\Users\GIGABYTE\opencode
    docker-compose -f docker-compose.android.yml build --no-cache
    docker-compose -f docker-compose.android.yml up

Ждите 20-40 минут.

📍 Результат: bin\magicartifact-0.1-debug.apk


▼▼▼ СПОСОБ 2: POWERSHELL СКРИПТ ▼▼▼

Откройте PowerShell ОТ АДМИНИСТРАТОРА и выполните:

    cd C:\Users\GIGABYTE\opencode
    .\install_buildozer_deps.ps1
    .\build_apk_local.ps1

Ждите 15-25 минут.

📍 Результат: bin\magicartifact-0.1-debug.apk


▼▼▼ СПОСОБ 3: ВСЁ СРАЗУ - ОДИН КЛИК ▼▼▼

Дважды кликните на файл:

    ЗАПУСТИ_СБОРКУ.bat

Автоматически выберет Docker или PowerShell.

📍 Результат: bin\magicartifact-0.1-debug.apk


═══════════════════════════════════════════════════════════════


🔍 ПРОВЕРКА ГОТОВНОСТИ (перед сборкой)

Откройте PowerShell и выполните:

    .\prepare_local_build.ps1

Это проверит все зависимости и покажет статус.

⚡ БЫСТРАЯ СБОРКА (если уже собирали раньше)

    cd C:\Users\GIGABYTE\opencode
    .\build_apk_local.ps1

(5-15 минут, используется кеш)

📋 ПОСЛЕ УСПЕШНОЙ СБОРКИ:

1. Проверка файла:
   ls -la bin\magicartifact-0.1-debug.apk

2. Установка на планшет (если подключен USB):
   adb install -r bin\magicartifact-0.1-debug.apk

3. Запуск приложения:
   adb shell am start -n org.magicartifact.magicartifact/.MainActivity

4. Просмотр логов (для отладки):
   adb logcat | findstr "python"
