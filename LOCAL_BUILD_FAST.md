# Локальная сборка APK - Быстро (5-10 минут на пересборку)

## Двухэтапный процесс

### Этап 1: Установка Android SDK (один раз, ~20 минут)

```powershell
# Запустите от администратора!
powershell -ExecutionPolicy Bypass -File "C:\Users\GIGABYTE\opencode\install_android_sdk.ps1"
```

Это установит:
- ✓ Android SDK (platform-tools, API 31)
- ✓ Build-tools 31.0.0
- ✓ NDK 25.1.8937393
- ✓ Переменные окружения

Займет 20-30 минут (большой NDK файл).

### Этап 2: Быстрая пересборка (5-10 минут)

После первой установки просто запускайте:

```powershell
# Из корня проекта
.\rebuild.ps1
```

Каждая пересборка занимает **5-10 минут** (кеш остается).

## Полный workflow

```powershell
# 1. Один раз установите SDK
powershell -ExecutionPolicy Bypass -File ".\install_android_sdk.ps1"

# 2. Закройте и откройте PowerShell (для загрузки env vars)

# 3. Меняете код в main.py
# ...редактируете...

# 4. Пересобираете APK
.\rebuild.ps1

# 5. Устанавливаете на устройство
adb install -r bin/magicartifact-0.1-debug.apk

# 6. Тестируете, повторяете с п.3
```

## Скорость сборки

| Этап | Время | Примечание |
|------|-------|-----------|
| SDK установка (один раз) | 20-30 мин | Без интернета |
| Первая сборка APK | 10-20 мин | Первый раз компилируется |
| Пересборка (после изменений) | 5-10 мин | **БЫСТРО** |

## Что устанавливается

```
C:\Users\{User}\.android-sdk\
├── cmdline-tools/latest/    (SDK tools)
├── platform-tools/          (adb, fastboot)
├── platforms/android-31/    (Android API 31)
├── build-tools/31.0.0/      (Compiler)
└── ndk/25.1.8937393/        (~3 ГБ)
```

**Итого: ~8 ГБ на диске**

## Если что-то не работает

```powershell
# Полная пересборка (очистка кеша)
.\rebuild.ps1 -Clean

# Проверка путей
$env:JAVA_HOME
$env:ANDROID_HOME

# Проверка Buildozer
buildozer --version

# Проверка Java
java -version
```

## Установка APK на устройство

```powershell
# На подключенное устройство или эмулятор
adb install -r bin/magicartifact-0.1-debug.apk

# Запуск приложения
adb shell am start -n org.magicartifact.magicartifact/.MainActivity

# Просмотр логов
adb logcat python:D *:S
```

## Рекомендация

Если планируете итерировать много раз:
1. Потратьте 20 минут на установку SDK
2. Потом каждая пересборка 5-10 минут
3. Экономия времени при 3+ пересборках

## Помощь

Если установка SDK зависает:
- Проверьте интернет соединение
- Убедитесь, что antivirus не блокирует скачивание
- Перезагрузитесь и повторите

Успеха!
