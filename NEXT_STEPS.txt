ШАГИ:

1. СБОР APK В COLAB
   ─────────────────────────────────────────────────────────────────────────
   
   1.1. Откройте COLAB_BUILD_FINAL.ipynb в Google Colab
        https://colab.research.google.com/
   
   1.2. Загрузите archiv opencode.zip (содержит обновленный main.py с логированием)
   
   1.3. Запустите ячейки по порядку:
        - Ячейка 1: Распаковка проекта
        - Ячейка 2: Установка зависимостей
        - Ячейка 3: Android SDK (10-15 минут)
        - Ячейка 4: СБОРКА APK (60-120 минут)
        - Ячейка 5: Скачивание APK
   
   1.4. Скачайте magicartifact-0.1-debug.apk из Files → /content


2. УСТАНОВКА В ЭМУЛЯТОР
   ─────────────────────────────────────────────────────────────────────────
   
   2.1. Поместите APK в: C:\Users\GIGABYTE\opencode\bin\
   
   2.2. Откройте PowerShell от администратора:
   
       powershell -ExecutionPolicy RemoteSigned
   
   2.3. Перейдите в папку проекта:
   
       cd C:\Users\GIGABYTE\opencode
   
   2.4. Добавьте adb в PATH:
   
       $env:Path += ";C:\Users\GIGABYTE\AppData\Local\Android\Sdk\platform-tools"
   
   2.5. Установите APK:
   
       adb install -r bin\magicartifact-0.1-debug.apk
   
   2.6. Запустите приложение:
   
       adb shell am start -n org.magicartifact.magicartifact/org.kivy.android.PythonActivity


3. ПРОСМОТР ЛОГОВ
   ─────────────────────────────────────────────────────────────────────────
   
   Откройте второе окно PowerShell и выполните:
   
       adb logcat | findstr python
   
   Увидите все логи приложения в реальном времени.


4. ПЕРЕУСТАНОВКА ПОСЛЕ ИЗМЕНЕНИЙ
   ─────────────────────────────────────────────────────────────────────────
   
   Каждый раз когда пересобираешь APK в Colab:
   
       adb install -r bin\magicartifact-0.1-debug.apk
       adb shell am start -n org.magicartifact.magicartifact/org.kivy.android.PythonActivity
