# 🚀 Сборка APK - Начни сейчас!

## Шаг 1: Запусти Docker Desktop

1. **Найди Docker Desktop** на рабочем столе или в меню Пуск
2. **Запусти** его (первый запуск может занять минуту)
3. **Дождись**, пока он полностью загрузится (значок станет активным)

![Docker Status](https://docs.docker.com/guides/docker-concepts/using-docker-images/images/docker-ready.png)

## Шаг 2: Запусти сборку APK

Открой **PowerShell от администратора** и выполни:

```powershell
cd C:\Users\GIGABYTE\opencode
.\build_docker.bat
```

Или просто **дважды клацни** на файл:
```
build_docker.bat
```

## Что будет происходить:

1. ⏳ **Docker образ будет собран** (10-15 минут, только первый раз)
2. 🔨 **APK будет собран** (30-60 минут, зависит от интернета)
3. ✅ **Файл APK появится** в папке `bin/`

## Индикатор прогресса:

```
[===>___________] Downloading SDK... (50%)
[=======>_______] Installing NDK... (65%)
[===========>___] Building APK... (78%)
```

## Результат

Когда процесс закончится, ты увидишь:
```
========================================================
          Сборка завершена успешно!
========================================================

APK файл создан: bin\magicartifact-0.1-debug.apk
```

## Шаг 3: Установка на планшет

После сборки APK:

### Через ADB (если установлен):
```powershell
adb install -r bin\magicartifact-0.1-debug.apk
```

### Или скопируй файл на планшет:
1. Найди файл `bin/magicartifact-0.1-debug.apk`
2. Скопируй на планшет через USB
3. На планшете откройте файл и установите

## Требования:

- ✅ Docker Desktop установлен и запущен
- ✅ ~4 GB свободного места на диске
- ✅ Интернет соединение (для скачивания SDK)

## Если что-то не работает:

### Docker не запускается:
```
Включи виртуализацию в BIOS:
- Перезагрузи компьютер
- Нажми Del (или F2/F12) при загрузке
- Найди "Virtualization" или "VT-x"
- Включи
```

### "Docker command not found":
```
Переустанови Docker Desktop и перезагрузи компьютер
```

### Сборка очень долгая:
```
Это нормально! 
- Первая сборка: 45-60 минут
- Последующие: 10-20 минут
```

## Готово! 🎉

Как только APK готов, ты сможешь установить его на планшет и начать использовать приложение.

**Примечание**: Приложение работает в полноэкранном режиме и слушает микрофон на слово "артефакт".
