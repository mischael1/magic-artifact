# 🎭 Магический Артефакт - Голосовое приложение для LARP

Приложение для планшета для использования на полевых ролевых играх. Постоянно прослушивает окружение, ждет слова пробуждения "артефакт", а затем распознает заклинания и воспроизводит эффекты.

## 🎯 Основные возможности

- 🎤 **Постоянное прослушивание** - ждет слова пробуждения "артефакт"
- 🔮 **Распознавание заклинаний** на русском языке:
  - "щит" - Магический щит
  - "огненный шар" - Огненный шар
  - "лечение" - Лечение
  - "молния" - Молния
  - "темная стрела" - Темная стрела
- 🎬 **Мультимедиа эффекты** - видео, аудио, изображения
- 📱 **Киоск-режим** - полноэкранное отображение
- ⚙️ **Офлайн работа** - не требует интернета
- 🌙 **Экран всегда включен** - режим низкого энергопотребления

## 🚀 Быстрый старт (3 способа)

### Способ 1: GitHub Actions (облако, самый простой)
```bash
git init && git add . && git commit -m "init" && git push
# На GitHub создайте .github/workflows/build.yml (см. QUICK_BUILD.md)
# Скачайте APK из Artifacts через 15-25 минут
```

### Способ 2: Локальная сборка в WSL2 на Windows
```bash
wsl --install -d Ubuntu-22.04  # Первый раз
# В WSL установите buildozer и Android SDK
cd /mnt/c/Users/GIGABYTE/opencode
python3 build_apk.py
```

### Способ 3: Прямая установка (если у вас уже есть APK)
```bash
adb install -r bin/magicartifact-0.1-debug.apk
```

## 🔧 Технологический стек

- **Фреймворк**: Kivy 2.3.1 (кроссплатформенный UI)
- **Язык**: Python 3.9+
- **Сборка**: Buildozer (автоматизация создания APK)
- **Целевая платформа**: Android 5.0+ (API 21+)
- **Архитектура**: ARM64 (arm64-v8a)

## 📝 Конфигурация заклинаний

Заклинания хранятся в `data/spells.json`:

```json
{
  "meta": {
    "wake_word": "артефакт",
    "auto_reset_timeout": 30
  },
  "spells": {
    "магический_щит": {
      "name": "Магический щит",
      "trigger_words": ["щит", "защита", "shield"],
      "media": {
        "video": "spells/shield/video.mp4",
        "sound": "spells/shield/sound.mp3",
        "image": "spells/shield/image.jpg"
      },
      "duration": 4000
    }
  }
}
```

## 🔐 Требования к медиафайлам

**Звук** (MP3):
- Формат: MP3, 128-320 kbps
- Канал: Mono or Stereo
- Частота: 44.1 kHz

**Видео** (MP4):
- Кодек: H.264
- Разрешение: 1280x720 или выше
- FPS: 30

**Изображения** (JPG/PNG):
- Размер: 1280x720 или больше
- Формат: JPG (лучше) или PNG

## 🎮 Использование на игре

1. **Подготовка**: Включите приложение за 5 минут до игры
2. **Ожидание**: Приложение слушает окружение
3. **Пробуждение**: Когда говорят "артефакт" - приложение активируется
4. **Заклинание**: Произнесите название заклинания
5. **Эффект**: Воспроизводится мультимедиа эффект
6. **Автосброс**: Через 30 сек приложение вернется в режим ожидания

## 🐛 Известные ограничения

- В текущей версии используется **простое распознавание звука** (вместо точного распознавания "артефакт")
- Распознавание заклинаний работает по **простому совпадению текста** (не требует идеального произношения)
- На эмуляторе **не работает звук** (только на реальном устройстве)
- **Тестовое распознавание речи** - на реальном планшете используется встроенный Android SpeechRecognizer
