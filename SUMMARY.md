### 📱 Как получить APK

**Вариант 1: GitHub Actions (РЕКОМЕНДУЕТСЯ)**
- Время: 25 минут облачной сборки
- Сложность: Очень простая
- Требует: GitHub репозиторий
- Процесс: Создайте .github/workflows/build.yml и запустите

**Вариант 2: WSL2 на Windows**
- Время: 3 часа (первый раз), 15 мин (потом)
- Сложность: Средняя
- Требует: WSL2, Android SDK/NDK, buildozer
- Процесс: Следуйте INSTALLATION.md

**Вариант 3: Linux/Mac**
- Время: 15-20 минут
- Сложность: Средняя
- Требует: Android SDK/NDK, buildozer
- Процесс: Запустите build_apk.py

### 🚀 Следующие шаги для вас

1. **Выберите способ сборки** (рекомендуется GitHub Actions)
