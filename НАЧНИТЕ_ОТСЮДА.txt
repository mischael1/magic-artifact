Выбери ОДИН вариант:

1️⃣  DOCKER (РЕКОМЕНДУЕТСЯ) - Самый надежный
────────────────────────────────────────────
    Требования:
    - Docker Desktop установлен и запущен
    - ~8 GB свободного места

    Команды:
    1. Откройте PowerShell или cmd
    2. Перейдите в папку проекта:
       cd C:\Users\GIGABYTE\opencode
    
    3. Запустите:
       docker-compose -f docker-compose.android.yml build --no-cache
       docker-compose -f docker-compose.android.yml up
    
    Ждите 20-40 минут
    ✅ APK появится в: bin\magicartifact-0.1-debug.apk


2️⃣  POWERSHELL - Установка в Windows
────────────────────────────────────────────
    Требования:
    - Python 3.9+
    - Java JDK 11+
    - ~8 GB свободного места

    Команды:
    1. Откройте PowerShell ОТ АДМИНИСТРАТОРА
    2. Перейдите в папку:
       cd C:\Users\GIGABYTE\opencode
    
    3. Запустите установку (один раз):
       .\install_buildozer_deps.ps1
    
    4. Запустите сборку:
       .\build_apk_local.ps1
    
    Ждите 15-25 минут
    ✅ APK появится в: bin\magicartifact-0.1-debug.apk

После сборки APK:

1. Проверьте файл:
   ls -la bin\magicartifact-0.1-debug.apk

2. Установите на планшет:
   - Способ 1: adb install -r bin\magicartifact-0.1-debug.apk
   - Способ 2: Скопируйте файл на USB и установите вручную

3. Протестируйте приложение:
   - Скажите "артефакт" (wake-word)
   - Произнесите заклинание

4. При изменениях кода:
   - Пересоберите (значительно быстрее, чем Colab!)

===============================================
  💾 КЕШИРОВАНИЕ
===============================================

Android SDK скачивается один раз (2 GB).
Дальше переиспользуется из кеша:
- Docker: .buildozer/  (в контейнере)
- PowerShell: %USERPROFILE%\.buildozer

Это ускоряет пересборку в 3-4 раза!

===============================================
  ⚠️  ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
===============================================

1. Docker не запускается:
   → Перезагрузите Docker Desktop
   → Включите виртуализацию в BIOS
   → Используйте PowerShell способ

2. Python не найден:
   → Установите Python 3.9+ (python.org)
   → Добавьте в PATH

3. Java не найдена:
   → Установите JDK 11+ (oracle.com)
   → Установите JAVA_HOME

4. Долгая сборка:
   → Это нормально! Первый раз 30-40 минут
   → Потом 5-15 минут

Детали в: ЛОКАЛЬНАЯ_СБОРКА.md → "🐛 Проблемы и решения"
