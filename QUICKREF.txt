📱 СПОСОБЫ ПОЛУЧИТЬ APK:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. ОБЛАКО (GitHub Actions) - САМЫЙ ПРОСТОЙ ⭐
   Время:       25 минут
   Установка:  Ничего не нужно
   Шаги:
     1. Загрузите проект на GitHub
     2. Создайте .github/workflows/build.yml
     3. GitHub собирает APK
     4. Скачайте
   Инструкция: QUICK_BUILD.md

2. WINDOWS - WSL2 + buildozer
   Время:       3+ часа (первый раз)
   Установка:  WSL2 + Android SDK
   Шаги:
     1. wsl --install -d Ubuntu-22.04
     2. Установите buildozer и Android SDK в WSL
     3. buildozer android debug
   Инструкция: INSTALLATION.md → Способ 2

3. LINUX/MAC - Быстро
   Время:       15-20 минут
   Установка:  Android SDK + buildozer
   Шаги:
     1. Установите зависимости
     2. python3 build_apk.py
   Инструкция: BUILD_APK.md


📥 КАК УСТАНОВИТЬ НА ПЛАНШЕТ:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Подключите планшет → adb install -r bin/magicartifact-0.1-debug.apk

Если нет adb:
  1. Скопируйте APK на планшет через USB
  2. Откройте файловый менеджер на планшете
  3. Найдите APK и нажмите → Установить

🔑 КЛЮЧЕВЫЕ КОМАНДЫ:

# Посмотреть логи
adb logcat | grep magicartifact

# Запустить приложение
adb shell am start -n org.magicartifact/.MainActivity

# Очистить данные приложения
adb shell pm clear org.magicartifact

# Удалить приложение
adb uninstall org.magicartifact
