🚀 КАК СОБРАТЬ APK:

ВАРИАНТ 1: GOOGLE COLAB (РЕКОМЕНДУЕТСЯ)
───────────────────────────────────────

Самый простой способ - всё в облаке!

1. Откройте: https://colab.research.google.com
2. Загрузите notebook: COLAB_BUILD.ipynb
3. Загрузите ZIP: opencode.zip
4. Запустите 5 ячеек
5. Скачайте APK файл

Время: 30-45 минут
Требует: Google аккаунт

Подробная инструкция: COLAB_ИНСТРУКЦИЯ.md
Быстрый старт: COLAB_QUICKSTART.txt


ВАРИАНТ 2: DOCKER (На Windows)
───────────────────────────────

Если Docker Desktop установлен:

  python build_apk_docker.py

или

  build_docker.bat

Время: 45-60 минут (первый раз)
Требует: Docker Desktop


ВАРИАНТ 3: WSL2 (На Windows)
─────────────────────────────

Если WSL2 установлена:

  wsl
  cd /mnt/c/Users/GIGABYTE/opencode
  buildozer android debug

Время: 30-45 минут
Требует: WSL2 + Ubuntu

📱 ПОСЛЕ СБОРКИ - УСТАНОВКА НА ПЛАНШЕТ:

Способ 1: ADB (рекомендуется)
──────────────────────────────

  1. Подключите планшет по USB
  2. На планшете включите режим разработчика
  3. Разрешите отладку по USB
  4. Выполните:
  
     adb install -r magicartifact-0.1-debug.apk


Способ 2: Копирование файла
────────────────────────────

  1. Скопируйте APK на планшет через USB
  2. На планшете откройте файл
  3. Нажмите "Установить"
  4. Разрешите установку из неизвестных источников
