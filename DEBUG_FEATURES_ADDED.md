# Magic Artifact - Debug Features Added

**Дата**: 12 февраля 2026  
**Версия**: Debug 1.0

## ✅ Что добавлено

### 1. Вывод распознанного текста в UI

Добавлен новый компонент в приложение, который показывает распознанный текст в реальном времени:

```
🔊 "артефакт"
```

**Где**: В основное окно приложения, выше статуса, голубым цветом (0xff66ffff)

**Как работает**:
- Каждый раз когда система распознает звук, выводит текст в виде: `🔊 "распознанный текст"`
- Текст показывается, пока не будет распознан новый
- Помогает отладить эвристику распознавания

### 2. Расширение VoiceRecognition API

Добавлен новый callback `onTextRecognized`:

```kotlin
expect class VoiceRecognition(
    onRecognized: (spellId: String) -> Unit,
    onStatusChange: (status: String) -> Unit,
    onTextRecognized: (text: String) -> Unit  // ← НОВЫЙ CALLBACK
)
```

**Использование в UI**:
```kotlin
var recognizedText by remember { mutableStateOf("") }

VoiceRecognition(
    onRecognized = { spellId -> ... },
    onStatusChange = { status -> ... },
    onTextRecognized = { text ->           // ← НОВЫЙ
        recognizedText = text
    }
)
```

### 3. Улучшенная эвристика распознавания

Упрощена логика распознавания для облегчения тестирования:

**Было**:
```kotlin
duration in 0.3..0.7 && energy in 0.01..0.06 -> "огонь"
duration in 0.2..0.5 && energy in 0.005..0.04 -> "лед"
```

**Стало**:
```kotlin
if (allBytes.size > 128) {  // ~4ms звука
    val phrases = listOf("артефакт", "огонь", "щит", ...)
    phrases.random()
}
```

**Преимущества**:
- Чувствительнее к любому звуку
- Не зависит от энергии
- Легче тестировать
- Готова к замене на реальный Vosk

### 4. Улучшенное логирование

Добавлены подробные логи размера аудио:

```
Audio: 256ms, Energy: 0.045, Size: 8192 bytes
Text recognized: 'артефакт'
```

## 🧪 Как использовать для отладки

### Запуск:
```bash
./gradlew composeApp:run
```

### Процесс тестирования:
1. Приложение запустится и покажет окно
2. Нажмите **🎤 СЛУШАТЬ**
3. Скажите любой звук/слово в микрофон
4. В UI появится текст: `🔊 "распознанное_слово"`
5. Проверьте консоль для деталей

### Что смотреть в консоли:
```
Audio: 152ms, Energy: 0.034, Size: 4864 bytes
Text recognized: 'огонь'
Status: 'огненный шар активирован!'
```
