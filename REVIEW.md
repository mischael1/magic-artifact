## Потенциальные проблемы и решения

### ⚠️ 1. Распознавание речи

**Проблема**: VOSK и openWakeWord сложно компилируются на Android  
**Решение**: Упрощена система на тестовый режим для сборки APK

**Для production**:
```python
# На реальном планшете использовать встроенный Android SpeechRecognizer
from android.intent import Intent
from android.os import Parcel
```

**Как это сделать**: Смотрите комментарии в `src/voice_manager.py`

### ⚠️ 2. Медиафайлы

**Проблема**: Нет реальных видео/звуков для заклинаний  
**Решение**: Программа работает без них (только UI)

**Как добавить**:
1. Положите MP3 файлы в `assets/spells/SPELL_NAME/sound.mp3`
2. Положите видео в `assets/spells/SPELL_NAME/video.mp4`
3. Положите изображения в `assets/spells/SPELL_NAME/image.jpg`
4. Программа автоматически найдет их

### ⚠️ 3. Киоск-режим

**Проблема**: Может быть требование полной блокировки экрана  
**Решение**: Сейчас использован полноэкранный режим Kivy

**Для true киоска**:
```python
# Добавить в AndroidManifest.xml
<uses-permission android:name="android.permission.ACCESS_KEYGUARD_SECURE_STORAGE"/>
<activity android:name=".MainActivity" android:systemUserHint="@string/config_shortPressOnHomeGoesToVoiceAssist"/>
```
