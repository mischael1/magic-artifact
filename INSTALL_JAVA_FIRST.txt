СПОСОБ 1: Автоматическая установка (PowerShell)
═════════════════════════════════════════════════

1. Найти файл: install_java.ps1 в папке проекта
2. Кликнуть правой кнопкой по файлу
3. Выбрать "Run with PowerShell"
4. Дождаться завершения установки

Или запустить из PowerShell:
  powershell -ExecutionPolicy Bypass -File "c:\Users\GIGABYTE\opencode\install_java.ps1"


СПОСОБ 2: Ручная установка
═════════════════════════════

1. Перейти на: https://adoptium.net/temurin/releases/
2. Скачать "OpenJDK 11 LTS" - "Windows x64 MSI"
3. Запустить MSI файл
4. Следовать инструкциям установщика


СПОСОБ 3: Проверить если Java уже есть
═════════════════════════════════════════

Открыть cmd и выполнить:
  java -version

Если команда работает - Java установлена и можно запускать приложение


ПОСЛЕ УСТАНОВКИ JAVA:
═════════════════════

Запустить файл: test_run.bat

Это скачает зависимости и запустит приложение.
