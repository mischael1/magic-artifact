# Docker Fast Build - Оптимально для итеративной разработки

## Что это?

Скорость сборки при многократных пересборках APK:

| Способ | Первая | Последующие |
|--------|--------|------------|
| Colab | 30-40 мин | 30-40 мин |
| Native (если бы работал) | 30-40 мин | 5-10 мин |
| Docker (этот метод) | 30-40 мин | **5-10 мин** ✓ |

**Docker сохраняет кеш сборки**, поэтому пересборка очень быстрая.

## Требования

- Docker Desktop для Windows (установлен ✓)
- PowerShell
- ~15 ГБ дискового пространства

## Первый запуск (30-40 минут)

```powershell
cd c:\Users\GIGABYTE\opencode
.\rebuild.ps1
```

Это:
1. Собирает Docker образ с Java, SDK, NDK
2. Запускает контейнер
3. Собирает APK

**После завершения контейнер остается живым!**

## Последующие пересборки (5-10 минут)

После изменения кода просто запустите:

```powershell
.\rebuild.ps1
```

Контейнер переиспользует:
- ✓ Java JDK (кеш)
- ✓ Android SDK (кеш)
- ✓ NDK (кеш)  
- ✓ Gradle кеш
- ✓ Maven кеш

Поэтому только код перекомпилируется (~5-10 минут).

## Команды

```powershell
# Первая сборка
.\rebuild.ps1

# Пересборка после изменений кода
.\rebuild.ps1

# Полная очистка Docker (если что-то сломалось)
.\rebuild.ps1 -Clean

# Затем снова первая сборка
.\rebuild.ps1
```

## Просмотр логов сборки

```powershell
docker-compose -f docker-compose.dev.yml logs buildozer -f
```

## Остановка контейнера

```powershell
docker-compose -f docker-compose.dev.yml down
```

Кеш сохранится в Docker volume, контейнер перезапустится быстро.

## Тестирование на устройстве

```powershell
# После сборки APK находится в bin/
adb install -r bin/magicartifact-0.1-debug.apk
```

## Как это работает

```
Ваш компьютер (Windows)
  ↓
  Docker контейнер (Linux)
    ├─ Java JDK (в контейнере, кеширован)
    ├─ Android SDK (в контейнере, кеширован)
    ├─ NDK (в контейнере, кеширован)
    └─ Volume mount: /app → ваш код на Windows
       (код обновляется, остальное из кеша)
  ↓
  bin/magicartifact-0.1-debug.apk
```

## Преимущества этого подхода

✓ Код меняется на Windows, как обычно  
✓ Все зависимости изолированы в контейнере  
✓ Кеш между пересборками  
✓ Не загрязняется система  
✓ Можно быстро удалить всё (`-Clean`)  
✓ Воспроизводимо на любом ПК с Docker  

## Проблемы?

### "docker not found"
```powershell
# Убедитесь, что Docker Desktop запущен
```

### "Failed to execute"
```powershell
# Смотрите логи:
docker-compose -f docker-compose.dev.yml logs
```

### "Permission denied"
```powershell
# Перезагрузите Docker Desktop
# Или запустите PowerShell от администратора
```
