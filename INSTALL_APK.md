# Установка Магического Артефакта на планшет

## Требования
- Планшет с Android 5.0+ (API 21+)
- Кабель USB для подключения
- Приложение ADB (Android Debug Bridge) на компьютере
- Включенный режим разработчика на планшете

## Шаг 1: Подготовка планшета

### На планшете:
1. Откройте **Настройки**
2. Прокрутите вниз и найдите **О телефоне** (или **О планшете**)
3. Нажмите на **Номер сборки** 7 раз подряд
4. Появится уведомление "Вы - разработчик"
5. Вернитесь в Настройки → **Дополнительные параметры** → **Параметры разработчика**
6. Включите **Отладка по USB**
7. Включите **Всегда разрешать с этого компьютера** (при запросе)

## Шаг 2: Сборка APK

### Вариант 1: На Linux/macOS
```bash
python3 build_apk.py
# или для чистой сборки:
python3 build_apk.py clean
```

### Вариант 2: На Windows с WSL2
```bash
# Запустите командный файл:
build_windows.bat
```

### Вариант 3: Использование Docker
```bash
docker build -t magic-artifact .
docker run -it -v $(pwd):/project magic-artifact python3 /project/build_apk.py
```

## Шаг 3: Установка на планшет

### Способ 1: Через ADB (рекомендуется)
```bash
adb install -r bin/magicartifact-0.1-debug.apk
```

### Способ 2: Копирование файла
1. Скопируйте файл `bin/magicartifact-0.1-debug.apk` на планшет через USB
2. На планшете откройте **Файловый менеджер**
3. Найдите файл APK
4. Нажмите на него для установки
5. Разрешите установку из неизвестного источника (если требуется)

### Способ 3: Прямой запуск APK на планшете
Если у вас есть файловый менеджер на планшете:
1. Передайте файл `magicartifact-0.1-debug.apk` на планшет
2. Откройте файл в файловом менеджере
3. Нажмите "Установить"

## Шаг 4: Запуск приложения

1. На планшете найдите приложение **Магический Артефакт**
2. Нажмите на него для запуска
3. Приложение войдет в полноэкранный режим
4. Скажите "артефакт" для активации
5. Скажите название заклинания для активации эффекта

## Доступные заклинания

- **Огненный шар**: "огненный шар", "фаер болл", "fireball"
- **Лечение**: "лечение", "хил", "heal", "исцеление"
- **Магический щит**: "щит", "защита", "shield", "магический щит"
- **Темная стрела**: "темная стрела", "дарк болт", "dark bolt"
- **Молния**: "молния", "электричество", "lightning", "разряд"

## Решение проблем

### Приложение не устанавливается
- Убедитесь, что включена опция "Неизвестные источники"
- Проверьте версию Android (должна быть 5.0+)
- Попробуйте удалить старую версию приложения

### Микрофон не работает
- Проверьте, что разрешено использование микрофона
- На планшете: Настройки → Приложения → Магический Артефакт → Разрешения → Микрофон
- Убедитесь, что на планшете есть рабочий микрофон

### Режим киоска не работает
- Режим киоска требует, чтобы приложение было установлено как системное приложение
- Или используйте стороннее приложение для управления киоском (KIOSK, Secure Kiosk и т.д.)

### Экран не остается включенным
- Приложение включает режим "Keep Screen On"
- Проверьте в Настройках → О планшете → Спящий режим

## Для разработчиков

### Опции сборки
```bash
# Debug версия (быстрая сборка, можно отлаживать)
python3 build_apk.py

# Чистая сборка (удаляет кэш)
python3 build_apk.py clean

# Release версия (для продакшена)
python3 build_apk.py release
```

### Логирование
Для просмотра логов приложения:
```bash
adb logcat | grep python
```

## Переустановка с сохранением данных
```bash
adb install -r bin/magicartifact-0.1-debug.apk
```

Флаг `-r` позволяет переустановить приложение без удаления его данных.
