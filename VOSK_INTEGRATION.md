# Vosk Integration для Magic Artifact

## Статус: В процессе интеграции

### Что сделано:
1. ✅ Обновлен `VoiceRecognition.kt` для работы с ключевым словом "артефакт"
2. ✅ Создан `SpellManager.kt` с базой заклинаний (8 заклинаний)
3. ✅ Обновлен `MagicArtifactApp.kt` для корректного сценария
4. ✅ Обновлен `build.gradle.kts` с версией Kotlin 2.0.21 и Compose 1.7.0
5. ✅ Добавлена поддержка Compose Hot Reload

### Сценарий работы:
1. Приложение ждет ключевое слово **"артефакт"**
2. При произнесении "артефакт" переходит в режим ожидания заклинания
3. Распознает заклинание из списка (щит, огонь, лед, молния, лечение, стрела, невидимость, телепорт)
4. Воспроизводит визуальный и звуковой эффект
5. Через 3 секунды возвращается в режим ожидания ключевого слова

### База заклинаний:
```
shield    - Магический Щит (щит, защита, protection)
fire      - Огненный Шар (огонь, пожар, flame)
ice       - Ледяная Стрела (лед, холод, freeze)
lightning - Молния (молния, гром, thunder)
heal      - Исцеление (лечение, здоровье, cure)
arrow     - Тёмная Стрела (стрела, темная, dark)
invisibility - Невидимость (невидимость, скрыться)
teleport  - Телепортация (телепорт, портал)
```

### Текущая реализация распознавания:
Используется простая эвристика на основе длительности и энергии звука. 
В будущем заменится на реальный Vosk с русской моделью.
