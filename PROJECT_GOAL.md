# 🎭 Магический Артефакт - Общая задача проекта

## Целевое назначение
Приложение для LARP игры (живого ролевого действа).

## Целевое устройство
**Lenovo Tab M10 FHD Plus (TB-X606X)**
- Экран: 10.3" IPS, 1920 x 1200
- ОС: Android 9.0 Pie+
- ОЗУ: 4GB
- Процессор: MediaTek Helio P22T
- Встроенный микрофон

## Требования к приложению

### Основной сценарий использования
1. Приложение запускается в режиме киоска (полноэкранно)
2. **Ожидание ключевого слова**: постоянно слушает микрофон в ожидании слова **"артефакт"**
3. **После активации**: ждёт произнесения заклинания
4. **Распознавание заклинания**: сравнивает транскрибированный текст с внутренней базой заклинаний
5. **Визуализация**: если заклинание найдено, приложение воспроизводит соответствующий эффект (видео, аудио, изображение)
6. **Автосброс**: через ~30 сек возвращается в режим ожидания ключевого слова

### Технические характеристики
- **Язык разработки**: Kotlin
- **Фреймворк**: Compose Multiplatform (для кроссплатформенности)
- **Распознавание речи**: Vosk (локальное распознавание, без интернета)
- **Автономность**: полностью офлайн, не требует сети и интернета
- **Точность**: реальное распознавание русской речи (текстовая транскрипция), а не анализ голоса или частных акустических характеристик

### База заклинаний (примеры)
- "щит" / "защита" → Магический щит
- "огненный шар" → Огненный шар
- "лечение" → Лечение
- "молния" → Молния
- "темная стрела" → Темная стрела
