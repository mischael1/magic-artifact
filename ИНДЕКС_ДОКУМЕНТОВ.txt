════════════════════════════════════════════════════════════════
   💡 ПОЛЕЗНЫЕ СОВЕТЫ
════════════════════════════════════════════════════════════════

1. Docker способ - РЕКОМЕНДУЕТСЯ
   ✓ Самый надежный
   ✓ Не влияет на систему
   ✓ Однородная среда
   
2. PowerShell способ - АЛЬТЕРНАТИВА
   ✓ Быстрее устанавливается
   ✓ Быстрее работает потом
   ✓ Но нужны Java и Python
   
3. Батник способ - САМЫЙ ЛЕГКИЙ
   ✓ Просто два клика
   ✓ Автоматический выбор способа
   
4. Первая сборка ДОЛГАЯ (30-40 мин)
   ✓ Это нормально!
   ✓ Потом будет 5-15 минут
   ✓ Благодаря кешу
   
5. Не удаляй .buildozer папку
   ✓ Это кеш для ускорения
   ✓ После удаления пересборка займет 30+ минут
   
6. При ошибке сборки:
   ✓ Прочитай ЛОКАЛЬНАЯ_СБОРКА.md
   ✓ Посмотри раздел "🐛 Проблемы"
   ✓ Если не поможет - пересборка с -Clean
