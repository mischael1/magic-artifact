# 🚀 ЗАПУСТИТЬ СЕЙЧАС

## ⏱️ 2 минуты на запуск

### Шаг 1: Открыть PowerShell
```powershell
# На Windows
Start-Process powershell -ArgumentList '-NoExit -Command "Set-Location C:\Users\GIGABYTE\opencode"'
```

### Шаг 2: Установить JAVA_HOME и запустить
```powershell
# В PowerShell скопируй и выполни:
$env:JAVA_HOME = 'C:\Program Files\Eclipse Adoptium\jdk-11.0.28.6-hotspot'
cd C:\Users\GIGABYTE\opencode
.\gradlew.bat composeApp:runDesktop
```

## 📋 Что произойдет

**Через 30-60 секунд**:
1. Градл загрузит зависимости
2. Компилирует код
3. Запустит приложение

## 🎤 Как использовать

1. **Нажми кнопку "🎤 СЛУШАТЬ"**
   - Кнопка станет зеленой "🎤 СЛУШАЮ..."
   - Статус: "Слушаю ключевое слово 'артефакт'"

2. **Скажи "артефакт"**
   - Статус: "Артефакт активирован! Скажите заклинание:"

3. **Скажи заклинание** (выбери один):
   - "щит" или "защита" → Магический Щит
   - "огонь" или "пожар" → Огненный Шар
   - "лед" или "холод" → Ледяная Стрела
   - "молния" или "гром" → Молния
   - "лечение" → Исцеление
   - "стрела" или "темная" → Тёмная Стрела
   - "невидимость" → Невидимость
   - "телепорт" → Телепортация

4. **Увидишь эффект**:
   - Статус: "ЗАКЛИНАНИЕ СРАБОТАЛО! [название]"
   - Центр артефакта станет **КРАСНЫМ**
   - Больше частиц (30 вместо 10)
   - Слышишь звуковой эффект

5. **Через 3 сек** вернется в режим ожидания

## 🎨 Визуальные эффекты

### Ждет ключевое слово
```
Фиолетовый центр
10 магических частиц вокруг
Мерцают цвета: розовый, голубой, фиолетовый
```

### После "артефакт"
```
Статус меняется

Артефакт еще фиолетовый
```

### Активное заклинание
```
Центр становится КРАСНЫМ ❤️
30 частиц летают вокруг
Звук определенной частоты
Мерцание (fade in/out)
```

## ❌ Если что-то не работает

### Нет окна приложения
```powershell
# Проверь Java
java -version

# Очисти кэш Gradle
.\gradlew.bat clean

# Попробуй снова
.\gradlew.bat composeApp:runDesktop
```

### Нет звука
- Проверь громкость Windows (не в режиме без звука)
- Перезагрузи приложение
- На Linux/Mac может требоваться дополнительная настройка звука

### Микрофон не работает
- На Windows: Settings > Privacy > Microphone → дай разрешение приложению
- Убедись, что микрофон физически подключен
- Попробуй в других приложениях

### Не распознает "артефакт"
- Говори медленнее и четче
- В Desktop версии работает эвристика, не точное распознавание
- Для точного используется Android версия с Vosk

2. Собери APK:
   ```powershell
   .\gradlew.bat assembleDebug
   ```

3. Установи на Lenovo Tab M10:
   ```powershell
   .\gradlew.bat installDebug
   ```

## 💡 Советы

- **Hot Reload разработка**: Измени цвет, сохрани - обновится автоматически
- **Добавить заклинание**: Отредактируй SpellManager.kt в commonMain
- **Новый звук**: Меняй частоту и модуляцию в SoundEffects.kt
- **Логи**: Смотри консоль при запуске для отладки
