# 🔨 Локальная сборка APK - Полное руководство

## Краткий старт (выбери один способ)

### Способ 1️⃣: Docker (рекомендуется) ⭐

Самый надежный способ - всё работает в изолированной среде.

```powershell
# 1. Убедись, что Docker Desktop запущен
docker ps  # Если работает - продолжаем

# 2. Перейди в папку проекта
cd C:\Users\GIGABYTE\opencode

# 3. Запусти сборку
docker-compose -f docker-compose.android.yml build --no-cache
docker-compose -f docker-compose.android.yml up

# Ждёшь 20-40 минут...
# APK появится в: bin\magicartifact-0.1-debug.apk ✅
```

**Требования:**
- Docker Desktop установлен и работает
- ~8 ГБ свободного места
- Интернет соединение

**Время:**
- Первый раз: 30-40 минут (скачивается Android SDK)
- Потом: 10-15 минут

---

### Способ 2️⃣: PowerShell скрипт

Запуск прямо в Windows, без Docker.

```powershell
# 1. Первая сборка - установи зависимости
cd C:\Users\GIGABYTE\opencode
.\install_buildozer_deps.ps1

# 2. Запусти сборку
.\build_apk_local.ps1

# Ждёшь 15-25 минут...
# APK появится в: bin\magicartifact-0.1-debug.apk ✅
```

**Требования:**
- Python 3.9+ (проверь: `python --version`)
- Java JDK 11+ ([скачать отсюда](https://www.oracle.com/java/technologies/javase-downloads.html))
- ~8 ГБ свободного места

**Время:**
- Первый раз: 20-25 минут
- Потом: 5-10 минут

---

### Способ 3️⃣: Прямая команда

Если скрипты не работают.

```powershell
# 1. Установка (один раз)
pip install buildozer cython

# 2. Сборка
cd C:\Users\GIGABYTE\opencode
buildozer android debug

# APK в: bin\magicartifact-0.1-debug.apk ✅
```

## ✅ После успешной сборки

### Проверка файла:
```powershell
ls -la bin\magicartifact-0.1-debug.apk
# Должно быть ~50-150 МБ
```

### Установка на планшет

**Если подключен через USB и есть ADB:**
```powershell
adb install -r bin\magicartifact-0.1-debug.apk

# Запуск приложения
adb shell am start -n org.magicartifact.magicartifact/.MainActivity
```

**Если ADB нет:**
1. Скопируй файл `bin\magicartifact-0.1-debug.apk` на USB флешку
2. Вставь флешку в планшет
3. Открой файл через файловый менеджер
4. Установи приложение

## 🐛 Проблемы и решения

| Проблема | Решение |
|----------|---------|
| **Docker не запускается** | 1. Перезагрузи Docker Desktop<br>2. Включи виртуализацию в BIOS<br>3. Попробуй PowerShell способ |
| **"Python не установлен"** | Установи Python 3.9+ с [python.org](https://www.python.org) |
| **"Java не найдена"** | Установи JDK 11+ ([oracle.com](https://www.oracle.com/java)) |
| **"buildozer: команда не найдена"** | `pip install buildozer cython` |
| **Недостаточно памяти** | Используй Docker (выделит нужный объём) |
| **Очень долгая сборка** | Это нормально первый раз! 20-40 минут OK |
| **Антивирус блокирует** | Добавь папку `.buildozer` в исключения |
| **"Cannot find SDK"** | Переустанови через PowerShell способ |

## 🚀 Ускорение пересборки

Если ты только менял код в `main.py` или `src/`:

```powershell
# Быстрая пересборка (не очищает кеш)
.\build_apk_local.ps1

# Если что-то странное, очистка + пересборка
.\build_apk_local.ps1 -Clean
```

⏱️ Не очищай кеш без необходимости - это экономит 20-30 минут!

## 💡 Совет

Docker способ - это как капсула для строительства. Всё что нужно внутри, ничего не влияет на компьютер.

PowerShell способ - это установка прямо в систему, быстрее, но требует настройки.

Выбери Docker если первый раз, PowerShell если уже знаешь что делаешь.
