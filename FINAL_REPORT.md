## 🚀 Как запустить СЕЙЧАС

### Desktop версия (самый быстрый способ)

```powershell
# В PowerShell (НЕ в cmd, НЕ в bash):
$env:JAVA_HOME = 'C:\Program Files\Eclipse Adoptium\jdk-11.0.28.6-hotspot'
cd C:\Users\GIGABYTE\opencode
.\gradlew.bat composeApp:runDesktop
```

**Время**: 30-60 секунд до появления окна

### Использование

1. Нажми **"🎤 СЛУШАТЬ"**
2. Скажи **"артефакт"**
3. Скажи **заклинание** (щит, огонь, лед, молния и т.д.)
4. Увидишь **эффект** (красный центр, 30 частиц, звук)

### Android версия (для планшета)

```bash
# Шаг 1: Скачать модель Vosk (один раз)
.\download_vosk_model.ps1

# Шаг 2: Собрать APK
.\gradlew.bat assembleDebug

# Шаг 3: Установить на планшет
adb install -r composeApp/build/outputs/apk/debug/composeApp-debug.apk
```
