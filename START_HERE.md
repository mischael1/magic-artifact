## 🚀 Как получить готовый APK (выберите вариант)

### Вариант A: Облако (GitHub Actions) ⭐ РЕКОМЕНДУЕТСЯ

**Самый простой, ничего не нужно устанавливать на компьютер**

1. Создайте GitHub репозиторий
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/YOUR_USERNAME/magic-artifact
   git push -u origin main
   ```

2. На GitHub: **Actions** → **set up a workflow** → скопируйте код из `QUICK_BUILD.md`

3. GitHub будет собирать APK за вас (15-25 минут)

4. Скачайте APK из Artifacts

**Плюсы**: Просто, бесплатно, никаких зависимостей  
**Минусы**: Нужно место на GitHub, время ожидания

## 📱 Как установить APK на планшет

Когда у вас есть файл `magicartifact-0.1-debug.apk`:

### Способ 1: ADB (рекомендуется)

```bash
# Подключите планшет по USB
# Включите режим разработчика (Settings → About → Build number 7x)

adb devices  # проверка
adb install -r bin/magicartifact-0.1-debug.apk
```

### Способ 2: Вручную через файловый менеджер

1. Скопируйте APK на планшет через USB
2. Откройте файловый менеджер
3. Нажмите на APK → Установить

Полная инструкция: **INSTALLATION.md**

## 🔧 Модификация заклинаний

Заклинания хранятся в `data/spells.json`:

```json
{
  "spells": {
    "магический_щит": {
      "name": "Магический щит",
      "trigger_words": ["щит", "защита", "shield"],
      "duration": 4000,
      "media": {
        "sound": "spells/shield/sound.mp3",
        "image": "spells/shield/image.jpg"
      }
    }
  }
}
```

Измените:
- `name` - название заклинания
- `trigger_words` - слова для активации
- `duration` - длительность эффекта в миллисекундах
- `media` - пути к видео/звукам/изображениям

После изменения просто переустановите приложение.

## 🐛 Помощь и проблемы

### Приложение не устанавливается
```bash
adb uninstall org.magicartifact
adb install -r bin/magicartifact-0.1-debug.apk
```

### Нет звука на планшете
1. Проверьте громкость
2. Убедитесь, что разрешен доступ к микрофону в Настройках

### Микрофон не работает
Settings → Apps → Magic Artifact → Permissions → Enable Microphone

### Приложение зависает при распознавании
В текущей версии это нормально - используется тестовое распознавание речи.  
На реальном устройстве будет работать встроенный Android SpeechRecognizer.

adb shell am start -n org.magicartifact/.MainActivity
