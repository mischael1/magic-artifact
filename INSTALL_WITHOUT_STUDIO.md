# ИНСТРУКЦИЯ ПО УСТАНОВКЕ ADB БЕЗ ANDROID STUDIO

## 🎯 СПОСОБ 1: СКАЧАТЬ OFFLINE ИНСТАЛЛЯТОР

### 1.1 Скачайте Command Line Tools
Скачайте ZIP файл с Android SDK Command Line Tools:
- Перейдите на: https://developer.android.com/studio/install
- Прокрутите вниз до "Command line tools only"
- Скачайте версию для Windows (около 146MB)

### 1.2 Распакуйте архив
```bash
# Распакуйте загруженный ZIP файл
unzip commandlinetools-win-*.zip -d "C:\adb"

# Проверяем распаковку
ls C:\adb
```

### 1.3 Добавьте в PATH
- Откройте "Свойства компьютера" → "Изменение переменных среды"
- Нажмите "Переменные среды"
- В разделе "Переменные пользователя" найдите "Path"
- Добавьте в конец: `;C:\adb\platform-tools`
- Сохраните изменения

### 1.4 Проверьте установку
```bash
# Перезапустите командную строку
adb version
# Должно показать версию ADB
```

## 🎯 СПОСБ 2: ПОДКЛЮЧЕНИЕ ПЛАНШЕТА И ЗАПУСК APK

### 2.1 Включите режим разработчика на планшете
1. Откройте "Настройки"
2. "О телефоне или планшете" → "Сведения о телефоне"
3. Нажмите 7 раз на "Номер сборки"
4. Появится опция "Режим разработчика" - включите

### 2.2 Подключите проверку приложения (опционально)
1. В настройках → "Безопасность"
2. Отключите "Проверка приложений через Play Защиту"

### 2.3 Разрешите установку из неизвестных источников
1. Настройки → "Безопасность"
2. Разрешите "Неизвестные источники"

## 🎯 СПОСБ 3: ПЕРЕДАЧА APK НА ПЛАНШЕТ

### 3.1 Создайте папку для APK
```bash
# В корневом каталоге создайте папку
mkdir MagicArtifactAPK
```

### 3.2 Проверьте наличие APK
```bash
cd "C:\Users\GIGABYTE\opencode"
ls bin/
```

Если файла нет, соберите APK:
```bash
cd "C:\Users\GIGABYTE\opencode"
buildozer -v android debug
```

### 3.3 Скопируйте APK в папку
```bash
copy "C:\Users\GIGABYTE\opencode\bin\MagicArtifactApp-debug.apk" "C:\adb\platform-tools\MagicArtifactApp-debug.apk"
```

### 3.4 Установите APK на планшет
```bash
# Установка APK
adb install "C:\adb\platform-tools\MagicArtifactApp-debug.apk"

# Проверка установки
adb shell pm list packages | findstr magicartifact
```

## 🎯 СПОСБ 4: ПРОВЕРКА РАБОТЫ

### 4.1 Проверка установки
```bash
# Должно вернуть название пакета
adb shell pm list packages | findstr magicartifact

# Проверка версии приложения
adb shell dumpsys package com.magicartifact | findstr versionName
```

### 4.2 Запуск приложения
```bash
# Запуск приложения
adb shell am start -n com.magicartifact/.MainActivity

# Или через иконку
adb shell monkey -p com.magicartifact -c android.intent.action.MAIN
```

### 4.3 Проверка логов (при проблемах)
```bash
# Просмотр логов в реальном времени
adb logcat | findstr MagicArtifact

# Сохранение логов в файл
adb logcat | findstr MagicArtifact > debug.log
```

## 🚨 ПОИСК И УСТРАНЕНИЕ ПРОБЛЕМ

### Проблема: "adb: command not found"
**Решение**: Проверьте что `C:\adb\platform-tools` добавлен в PATH

### Проблема: "device not found"
**Решение**: 
1. Проверьте включен ли режим разработчика на планшете
2. Отключите и снова включите USB-отладку
3. Попробуйте другой USB-кабель
4. Проверьте драйверы USB на компьютере

### Проблема: "INSTALL_FAILED_INSUFFICIENT_STORAGE"
**Решение**: Освободите место на планшете или установите на SD-карту

### Проблема: "INSTALL_FAILED_PERMISSION_DENIED"
**Решение**: Разрешите установку из неизвестных источников в настройках Android

### Проблема: Приложение крэшится при запуске
**Решение**: Проверьте совместимость с Android 5.0+ и ARM64 архитектурой
