⚡ САМЫЙ БЫСТРЫЙ СПОСОБ:
═══════════════════════════════════════════════════════════════

1. СКАЧАЙ И УСТАНОВИ DOCKER DESKTOP:
   https://www.docker.com/products/docker-desktop

2. ЗАПУСТИ DOCKER DESKTOP
   (значок в системном трее должен быть зеленый)

3. ВЫПОЛНИ ОДНУ ИЗ КОМАНД:

   Windows PowerShell:
   ────────────────────────────────────────────────────────
   cd C:\Users\GIGABYTE\opencode
   python build_apk_docker.py


   Или просто запусти файл:
   ────────────────────────────────────────────────────────
   build_docker.bat
   (двойной клик в Windows Explorer)


4. ЖДИ ☕
   Первый раз: 45-60 минут
   Потом: 10-20 минут


5. ПОЛУЧИ APK:
   ────────────────────────────────────────────────────────
   bin\magicartifact-0.1-debug.apk


═══════════════════════════════════════════════════════════════

📲 УСТАНОВКА НА ПЛАНШЕТ:

adb install -r bin\magicartifact-0.1-debug.apk

Или скопируй файл APK на планшет и открой его там.
