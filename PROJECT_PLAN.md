# План разработки "Магический Артефакт"

## Обзор проекта
Создание голосового приложения для ролевых игр, работающего в киоск-режиме на планшете Lenovo Tab M10 FHD Plus.

## Этапы разработки

### Этап 1: Установка окружения (1-2 часа)
- [ ] Установка Python 3.9+
- [ ] Установка Kivy и зависимостей
- [ ] Установка openWakeWord
- [ ] Установка VOSK
- [ ] Настройка Buildozer
- [ ] Установка Android SDK

### Этап 2: Базовое Kivy приложение (2-3 часа)
- [ ] Создание main.py
- [ ] Настройка полноэкранного режима
- [ ] Отключение спящего режима
- [ ] Создание фонового интерфейса
- [ ] Тестирование на эмуляторе

### Этап 3: Wake-word detection (3-4 часа)
- [ ] Настройка openWakeWord
- [ ] Обучение модели для фразы "артефакт"
- [ ] Интеграция с Kivy
- [ ] Тестирование прослушивания
- [ ] Оптимизация производительности

### Этап 4: Speech recognition (2-3 часа)
- [ ] Скачивание русской модели VOSK
- [ ] Настройка микрофона
- [ ] Тестирование распознавания
- [ ] Создание системы команд
- [ ] Обработка ошибок

### Этап 5: Система заклинаний (3-4 часа)
- [ ] Создание JSON базы заклинаний
- [ ] Настройка медиаплеера
- [ ] Система匹配 голоса с заклинаниями
- [ ] Автоматический сброс через 30 секунд
- [ ] Визуальные эффекты

### Этап 6: Тестирование и развертывание (2-3 часа)
- [ ] Тестирование на эмуляторе
- [ ] Сборка APK через Buildozer
- [ ] Установка на планшет Lenovo
- [ ] Финальная отладка
- [ ] Оптимизация производительности

## Архитектура проекта

### Структура файлов
```
MagicArtifactApp/
├── main.py                    # Главный файл приложения
├── buildozer.spec            # Конфигурация сборки Android
├── requirements.txt          # Зависимости Python
├── assets/                   # Ресурсы приложения
│   ├── background.jpg        # Фон артефакта
│   ├── sounds/              # Звуковые эффекты
│   └── spells/              # Медиа для заклинаний
├── models/                   # Модели распознавания
│   ├── wake_word_model.onnx
│   └── vosk-model-ru-0.42/
├── src/                      # Исходный код
│   ├── app.py               # Основное приложение Kivy
│   ├── voice_manager.py     # Управление голосом
│   ├── spell_manager.py     # Управление заклинаниями
│   └── media_player.py      # Проигрывание медиа
└── data/                    # Данные приложения
    └── spells.json          # База заклинаний
```

### Ключевые компоненты
1. **VoiceManager**: wake-word + speech recognition
2. **SpellManager**: база заклинаний и匹配
3. **MediaPlayer**: видео/аудио/изображения
4. **KivyApp**: основной интерфейс и киоск-режим

## Технические решения

### Почему выбраны эти инструменты?
- **Kivy**: бесплатный, Python, хорошая Android поддержка
- **openWakeWord**: open-source, кастомные wake words
- **VOSK**: бесплатный, офлайн, русский язык
- **Buildozer**: стандарт для Python Android приложений

### Альтернативы (рассмотрены и отклонены)
- **Porcupine**: платный для кастомных wake words
- **Kotlin/Java**: сложнее для пользователя с Python опытом
- **React Native**: избыточно для данной задачи

## Риски и митигации

### Технические риски
- **Производительность**: тестировать на реальном устройстве
- **Размер APK**: оптимизировать медиафайлы
- **Точность распознавания**: качественный микрофон, шумоподавление

### Решения проблем
- Использовать сжатые медиафайлы
- Оптимизировать модели распознавания
- Добавить ручные триггеры как запасной вариант

## Критерии успеха
- [ ] Приложение запускается в киоск-режиме
- [ ] Wake-word "артефакт" детектируется надежно
- [ ] Заклинания распознаются с точностью >80%
- [ ] Медиаэффекты воспроизводятся без задержек
- [ ] Автосброс работает через 30 секунд
