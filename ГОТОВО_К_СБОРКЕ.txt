🚀 БЫСТРЫЙ СТАРТ СБОРКИ

Вариант 1: Docker (РЕКОМЕНДУЕТСЯ)
───────────────────────────────────

1. Скачайте Docker Desktop:
   https://www.docker.com/products/docker-desktop

2. Установите и запустите Docker Desktop

3. Откройте PowerShell и выполните:
   
   cd C:\Users\GIGABYTE\opencode
   python build_apk_docker.py

   ИЛИ просто запустите файл:
   
   build_docker.bat


Вариант 2: WSL2 (БЫСТРЕЕ)
───────────────────────────

Если уже установлена WSL2 с Ubuntu:

   wsl
   cd /mnt/c/Users/GIGABYTE/opencode
   buildozer android debug


Вариант 3: Google Colab (ОБЛАКО)
──────────────────────────────────

   1. Откройте COLAB_BUILD.ipynb в Google Colab
   2. Запустите ячейки
   3. Скачайте готовый APK


Вариант 4: GitHub Actions
──────────────────────────

   1. Push на GitHub
   2. Автоматическая сборка в облаке
   3. Скачайте из Artifacts

🎯 ФУНКЦИОНАЛ ПРИЛОЖЕНИЯ

При запуске на планшете:

1. Полноэкранный режим (киоск)
2. Слушает пробуждение на слово "артефакт"
3. После пробуждения слушает названия заклинаний
4. Воспроизводит эффекты при распознавании:
   - Звуковые эффекты
   - Визуальные эффекты
   - Частицы магии

📦 ПОСЛЕ СБОРКИ

Файл APK создается в:
   bin/magicartifact-0.1-debug.apk

Установка на планшет:

   Способ 1: Через ADB
   adb install -r bin\magicartifact-0.1-debug.apk

   Способ 2: Скопировать и открыть на планшете
   - Передайте файл APK на планшет по USB
   - Откройте файл и установите

   Способ 3: Режим разработчика + отладка по USB
   - На планшете: Настройки → О телефоне → Номер сборки x7
   - Настройки → Разработчик → Отладка по USB
   - Выполните: adb install -r bin\magicartifact-0.1-debug.apk
