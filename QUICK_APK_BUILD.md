# БЫСТРЫЙ ЗАПУСК СБОРКИ APK

## Ситуация:
На этой системе:
- Python 3.13 ✓ установлен
- Buildozer 1.5.0 ✓ установлен
- Java ✗ НЕ установлена
- Docker ✓ установлен (но требует admin прав)

## Два пути:

### ПУТЬ 1: Установить Java и собрать native (5 минут)

1. Скачайте OpenJDK 11 с https://adoptopenjdk.net/ (или используйте choco)

```powershell
# В PowerShell (от администратора):
choco install openjdk11
```

2. После установки Java:

```powershell
cd c:\Users\GIGABYTE\opencode
buildozer android debug
```

Это займет 20-40 минут в первый раз (скачивание SDK).

---

### ПУТЬ 2: Использовать Google Colab (текущий метод, без изменений)

Если на системе сложно установить все зависимости, продолжаем использовать Colab - он уже сконфигурирован и работает.

---

## РЕКОМЕНДАЦИЯ:

**Путь 1 + Java** - надежнее и понятнее:

```powershell
# 1. Установка Java (один раз, если нет)
choco install openjdk11

# 2. Проверка
java -version

# 3. Сборка
buildozer android debug

# 4. APK будет в:
# bin/magicartifact-0.1-debug.apk
```

После этого для изменений кода нужно просто перелапустить `buildozer android debug` (будет намного быстрее благодаря кешу).
