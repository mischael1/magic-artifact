# История диалога и принятия решений

**Дата**: 22 января 2026
**Пользователь**: "У меня есть планшет Lenovo Tab M10 FHD Plus модель TB-X606X. Мне надо сделать для него приложение для использования на полевой ролевой игре без интернета, но с подключенным электричеством. То есть проблем по питанию не будет."

## Уточняющие вопросы и ответы

**Вопрос**: "Какие именно функции вам нужны в приложении для полевой ролевой игры?"

**Ответ пользователя**: "Нужно приложение для магии. в стиле 'магический артефакт'. Цель:
- Всегда на весь экран (киоск).
- Экран не гаснет.
- Постоянно слушает только для wake-word, а после него — распознаёт заклинание. Если заклинание произнесено верно, то показывает результат и/или включает соответствующее видео или аудио, показывает картинку. затем через 30 секунд опять переходит в режим слушания wake-word."

## Ключевые принятые решения

### 1. Технологический стек
**Решение**: Kivy + Python
**Обоснование**: 
- У пользователя есть опыт с Python
- Kivy бесплатный и open-source
- Хорошая поддержка Android
- Легко развертывается через Buildozer

**Альтернативы рассмотрены**:
- Kotlin/Java - отклонено (сложнее для пользователя)
- React Native - отклонено (избыточно)
- Flutter - отклонено (требует Dart)

### 2. Wake-word detection
**Решение**: openWakeWord
**Обоснование**:
- Полностью бесплатный
- Поддерживает кастомные фразы
- Работает на Python
- Open-source

**Альтернативы рассмотрены**:
- Porcupine (Picovoice) - отклонено (платный для кастомных слов)
- Собственная реализация - отклонено (сложно)

### 3. Speech recognition
**Решение**: VOSK
**Обоснование**:
- Бесплатный офлайн-распознавание
- Поддерживает русский язык
- Модели по ~50MB (приемлемо)
- Python API

**Альтернативы рассмотрены**:
- Google Speech API - отклонено (требует интернет)
- Whisper - отклонено (тяжелые модели)

### 4. Архитектура приложения
**Решение**: Киоск-режим + голосовое управление
**Ключевые компоненты**:
- Wake-word "артефакт"
- Speech recognition для заклинаний
- Медиаплеер для эффектов
- Автосброс через 30 секунд

## Анализ требований

### Функциональные требования
1. **Киоск-режим**: полноэкранный режим без системных панелей
2. **Отключение спящего режима**: экран не гаснет
3. **Wake-word detection**: постоянное прослушивание фразы "артефакт"
4. **Speech recognition**: распознавание заклинаний на русском языке
5. **Медиаэффекты**: видео/аудио/изображения для заклинаний
6. **Автосброс**: возврат к прослушиванию через 30 секунд

### Нефункциональные требования
1. **Офлайн работа**: без доступа к интернету
2. **Бесплатные инструменты**: только open-source решения
3. **Производительность**: работа на планшете Lenovo Tab M10
4. **Простота использования**: интуитивный интерфейс
5. **Надежность**: стабильная работа в течение игры

### Ограничения
1. **Устройство**: только Lenovo Tab M10 FHD Plus
2. **ОС**: Android 9+
3. **Память**: ограничена 32-128GB
4. **Процессор**: MediaTek Helio P22T
5. **Бюджет**: только бесплатные инструменты

## Риски и митигации

### Технические риски
1. **Производительность wake-word**: может быть медленной на ARM
   **Митигация**: оптимизация модели, тестирование
2. **Точность распознавания**: зависит от качества микрофона
   **Митигация**: шумоподавление, калибровка
3. **Размер APK**: модели распознавания увеличивают размер
   **Митигация**: сжатие, оптимизация

### Пользовательские риски
1. **Сложность настройки**: пользователь с небольшим опытом
   **Митигация**: детальные инструкции, пошаговый гайд
2. **Отладка на устройстве**: может быть сложной
   **Митигация**: эмулятор, логирование
