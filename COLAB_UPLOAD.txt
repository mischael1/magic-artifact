⚠️ ВАЖНО: Проект должен быть в Colab ПЕРЕД сборкой!

✅ СПОСОБ 1: ЗАГРУЗИТЬ ЧЕРЕЗ ZIP (РЕКОМЕНДУЕТСЯ)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. На своем компьютере:
   - Выделите папку: opencode
   - Щелкните правой кнопкой → Отправить → Сжатая папка (ZIP)
   - Получится: opencode.zip

2. В Google Colab:
   - Files (слева) → Upload file
   - Выберите opencode.zip
   - Дождитесь загрузки

3. В первой ячейке (перед остальным) добавьте:

   import zipfile
   import os
   
   # Распаковка проекта
   with zipfile.ZipFile('/content/opencode.zip', 'r') as zip_ref:
       zip_ref.extractall('/content')
   
   os.chdir('/content/opencode')
   print("✓ Проект загружен и готов к сборке")


✅ СПОСОБ 2: ЗАГРУЗИТЬ ФАЙЛЫ ВРУЧНУЮ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. В Google Colab:
   - Files (слева панель)
   - Upload folder
   - Выберите папку opencode со своего компьютера

2. Файлы будут в /content/opencode/


✅ СПОСОБ 3: БЫСТРО ЧЕРЕЗ PYTHON (ЕСЛИ ZIP УЖЕ ЗАГРУЖЕН)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Первая ячейка:

   import zipfile
   import os
   
   # Если файл opencode.zip уже в /content/
   with zipfile.ZipFile('/content/opencode.zip', 'r') as zip_ref:
       zip_ref.extractall('/content')
   
   os.chdir('/content/opencode')
   
   # Проверка
   print("Файлы в проекте:")
   print(os.listdir('.'))

ПОЛНЫЙ ПОРЯДОК ДЕЙСТВИЙ:

1️⃣ Создайте ZIP с проектом на своем ПК
   (папка opencode → правый клик → Сжать)

2️⃣ В Google Colab загрузите ZIP
   Files (слева) → Upload file → выберите opencode.zip

3️⃣ Создайте ПЕРВУЮ ячейку (распаковка):

   import zipfile
   import os
   
   with zipfile.ZipFile('/content/opencode.zip', 'r') as zip_ref:
       zip_ref.extractall('/content')
   
   os.chdir('/content/opencode')
   print("✓ Готово")

4️⃣ Запустите вторую ячейку (зависимости)

5️⃣ Запустите третью ячейку (Android SDK)

6️⃣ Запустите четвертую ячейку (СБОРКА APK) - это займет 10-20 мин

7️⃣ Скачайте APK из Files → bin → magicartifact-0.1-debug.apk

8️⃣ Установите на планшет:
   adb install -r magicartifact-0.1-debug.apk
