# Стратегия сборки APK

## Анализ вариантов на этой системе

### 1. Docker (localhost:2375 требует admin)
- ❌ Требует admin прав для Docker Socket
- ❌ Не работает без admin
- ⏸ Отложить на потом

### 2. Native Buildozer на Windows
- ❌ WSL Bash не поддерживает Android target
- ❌ Нет Java в PATH по умолчанию
- ❌ Требует полной установки SDK (~8 ГБ)
- ⏸ Требует слишком много настройки

### 3. Google Colab ✓ РЕКОМЕНДУЕТСЯ
- ✓ Всё уже установлено
- ✓ Работает из коробки
- ✓ 30-40 минут первый раз
- ✓ Пересборка 30-40 минут (нет локального кеша, но не критично)
- ✓ Бесплатно
- ✓ Не требует admin прав

---

## Рекомендованный workflow для разработки

### Для быстрого итеративного тестирования:

```
1. Делаете изменения кода в main.py
2. Коммитите в git: git add . && git commit -m "..."
3. Пушите: git push
4. Открываете COLAB_BUILD_FINAL.ipynb
5. Запускаете Ctrl+F9 (Run all)
6. Ждете 30-40 минут
7. Скачиваете APK
8. Устанавливаете на устройство: adb install -r bin/...apk
9. Тестируете
10. Повторяете с п.1
```

### Или используете Colab встроенный editor:

```
1. Откройте COLAB_BUILD_FINAL.ipynb в Colab
2. Клонируется последний код из git
3. Отредактируйте прямо в Colab (если нужны быстрые правки)
4. Запустите сборку
5. Скачайте APK
```

## Когда это будет быстрее?

### Если установить Java + Android SDK локально
- Первая сборка: 30-40 минут
- **Пересборка: 5-10 минут** ✓ НАМНОГО БЫСТРЕЕ

Но это требует:
- Установить Java JDK (~300 МБ) - 5 минут
- Установить Android SDK (~8 ГБ) - 20-30 минут
- Установить NDK (~3 ГБ) - 15-20 минут
- Настроить переменные окружения - 5 минут
- **ИТОГО: 50-90 минут на подготовку**

Если вы планируете много пересборок (20+), то стоит потратить время на подготовку.
