    ├─ Потом: 5-10 минут
    └─ Требует: Python 3.9+ и Java JDK 11+

3️⃣  БАТНИК (ОДИН КЛИК) ⭐⭐⭐

═══════════════════════════════════════════════════════════════
  ⏱️  ВРЕМЯ СБОРКИ
═══════════════════════════════════════════════════════════════

Первый раз (скачивается Android SDK):

   Docker:        20-40 минут
   PowerShell:    15-25 минут
   Батник:       Зависит от выбранного способа

Последующие разы (используется кеш):

   Docker:        10-15 минут
   PowerShell:    5-10 минут
   Батник:       5-15 минут

Ускорение кеша:
   • Android SDK скачивается один раз (~2 GB)
   • Потом переиспользуется из .buildozer
   • Это ускоряет пересборку в 3-4 раза!

═══════════════════════════════════════════════════════════════

После успешной сборки APK (в bin/):

СПОСОБ 1 - ADB (быстро):
  adb install -r bin\magicartifact-0.1-debug.apk
  (требует подключенного Android устройства)

СПОСОБ 2 - USB копирование (если нет ADB):
  1. Скопировать APK на USB флешку
  2. Вставить флешку в планшет
  3. Открыть файл в файловом менеджере
  4. Установить приложение

Запуск приложения:
  adb shell am start -n org.magicartifact.magicartifact/.MainActivity
